# ☕ Coffee Sales Dashboard

An interactive sales analytics dashboard built with Python, Streamlit & Plotly.

## 📌 Problem Statement
Analyze 1400+ coffee shop transactions to uncover revenue patterns,
top-selling products, and customer payment behavior.

## 🔍 Key Insights
- Top 3 products by revenue
- Peak sales hours / days
- Most common payment methods
- Average transaction value

## 🛠️ Tech Stack
Python · Pandas · Streamlit · Plotly · CSV Data

## 🚀 How to Run
pip install -r requirements.txt
streamlit run Coffee_Dashboard.py
